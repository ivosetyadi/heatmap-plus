# 📈 Heatmap+

A **richer GitHub contribution card** as an SVG — total contributions, current & longest streak, busiest weekday, and a mini heatmap. Generated by a GitHub Action and committed into your repo, so you can show it in your profile README with **no hosting and no API token**.

Part of [DevGuard Tools](https://ivosetyadi.github.io).

## Usage

Add a workflow that renders the card on a schedule and commits it:

```yaml
# .github/workflows/heatmap.yml
name: Heatmap+
on:
  schedule: [{ cron: '0 3 * * *' }]   # daily
  workflow_dispatch:
permissions:
  contents: write
jobs:
  render:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: ivosetyadi/heatmap-plus@v1
        with:
          theme: dark          # user defaults to the repo owner
          output: heatmap.svg
          commit: true
```

Then reference the committed file in your README:

```markdown
![My GitHub activity](./heatmap.svg)
```

## Inputs

| Input | Default | Description |
|-------|---------|-------------|
| `user` | repo owner | GitHub username to render |
| `theme` | `light` | `light` \| `dark` \| `dracula` |
| `output` | `heatmap.svg` | file path to write |
| `commit` | `true` | commit & push the SVG if it changed |
| `commit-message` | `chore: update contribution heatmap [skip ci]` | — |

## What it shows

- **Total contributions** in the last year
- **Current streak** and **longest streak** (consecutive active days)
- **Most productive weekday**
- A compact 6-month heatmap

## How it works

The Action fetches `github.com/users/<user>/contributions` (public, unauthenticated), parses the day cells, computes the stats, and renders an SVG. The parse/stats/render logic lives in `lib.js` as pure functions — see `test/run.mjs` (15 assertions, no network).

```bash
npm test   # offline unit tests
```
